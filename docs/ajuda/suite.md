# Suíte Angerô — Ajuda

O iniciador **Suíte Angerô** (ícone da folha, na Área de Trabalho e no Menu Iniciar) reúne os programas,
a busca de arquivos, as extensões e o **Assistente Angerô**.

## Tela inicial

- **Programas:** clique em **Abrir**. O status mostra se o programa está aberto.
- **Plugins:** extensões instaladas (ex.: Fluxogama - Angerô).
- **Abrir arquivo:** digite parte do nome e clique em **Procurar**, ou use **📂 Escolher arquivo…** para navegar
  pelas pastas. Em cada resultado: **Abrir no …** (abre no programa certo) ou **📁 Mostrar na pasta**.
- **Atualizações:** versão de cada programa e o que foi atualizado. **↻ Procurar atualizações agora** força a verificação.

## Assistente Angerô

Escreva o que precisa, em português:

- *"Abra o Illustre"*
- *"Procure o arquivo Mix Pijamas e abra"*
- *"Exporte a segunda prancheta em JPG na Área de Trabalho"*
- *"Como faço contorno tracejado?"*

Primeira vez: **⚙ Configurações** › cole a **chave do Google Gemini** (grátis em aistudio.google.com › Get API key)
› **Testar** › **Salvar**. A chave fica só neste computador.

> No plano gratuito o Google pode usar o que é digitado no chat para melhorar os produtos dele.
> Não envie informações sigilosas de coleção pelo assistente. Os arquivos em si não são enviados.

## Extensões (Illustre)

Com o Illustre aberto, use o botão **🧩 Extensões** no alto da janela. Para instalar uma extensão, copie a pasta
dela para `plugins\` dentro da pasta da Suíte (o menu **Abrir pasta de extensões** leva até lá).
Em ⚙ Configurações dá para abrir o Fluxogama automaticamente junto com o Illustre.

## Atualização automática

A Suíte confere o GitHub ao abrir e a cada 6 horas. Programas fechados são atualizados na hora;
os abertos, quando forem fechados. Não precisa de senha de administrador.

Outras dúvidas: fale com o TI do Grupo Angerô.
