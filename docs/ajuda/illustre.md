# Illustre - Angerô — Ajuda

Programa de **desenho vetorial** da Suíte Angerô: fichas técnicas, estampas, desenhos planificados e artes.
Os menus, as ferramentas e os atalhos seguem o padrão do Illustrator, então quem já usa o Illustrator se acha rápido.

## Abrir

- Menu Iniciar › **Suíte Angerô** › **Illustre - Angerô**, ou pelo iniciador **Suíte Angerô**.
- Arquivos que ele abre: `.ai` (a parte compatível com PDF), `.svg`, `.eps`, `.pdf`, `.dxf`, `.emf`, imagens.

> **Arquivos `.ai`:** o Illustre lê o desenho completo do `.ai`, mas salva sem os dados de edição exclusivos
> do Illustrator. Se o arquivo ainda vai voltar para alguém que usa o Illustrator, salve com **outro nome**.

## Onde fica cada coisa

| Quero… | Onde |
|---|---|
| Criar um documento | Arquivo › Novo (Ctrl+N) |
| Abrir | Arquivo › Abrir (Ctrl+O) |
| Exportar JPG/PNG/PDF | Arquivo › Exportar › Exportar como… (cada prancheta pode virar um arquivo) |
| Pranchetas | Ferramenta Prancheta (Shift+O) ou Objeto › Pranchetas |
| Contorno tracejado | Janela › Traçado (Ctrl+F10) › marque **Linha tracejada** e ajuste traço/espaço |
| Camadas | Janela › Camadas (F7) |
| Alinhar | Janela › Alinhar (Shift+F7) |
| Pathfinder (unir, subtrair…) | Janela › Pathfinder (Ctrl+Shift+F9) |
| Cores da marca | Janela › Amostras |
| Texto em caminho | Ferramenta Texto no caminho |
| Vetorizar imagem | Objeto › Rastreamento de imagem › Criar |
| Fontes que faltam | Texto › Localizar fonte… |

Atalhos mais usados: **V** seleção, **A** seleção direta, **P** caneta, **T** texto, **M** retângulo, **L** elipse,
**Ctrl+G** agrupar, **Ctrl+Z** desfazer, **Ctrl+Shift+Z** refazer, **Ctrl+0** encaixar prancheta na tela.

## Extensões (Fluxogama)

No alto da janela do Illustre fica o botão **🧩 Extensões**. Ele lista as extensões instaladas.
**Fluxogama - Angerô** abre a galeria de modelos encaixada à direita:
abrir a arte de um modelo no Illustre e enviar as pranchetas do documento aberto para o portal
(o documento precisa estar salvo).

## Assistente de IA

No iniciador **Suíte Angerô**, o **Assistente Angerô** abre o Illustre, procura e abre arquivos, exporta pranchetas
e explica as ferramentas. Exemplos: *"abre a ficha Mix Pijamas"*, *"exporta a prancheta 2 em JPG"*,
*"como faço contorno tracejado?"*.

## Problemas comuns

- **O texto apareceu em outra fonte:** a fonte original não está instalada neste computador. Instale-a (peça ao TI) ou
  use Texto › Localizar fonte… para trocar.
- **Abriu com tudo numa camada só:** normal para `.ai` — o Illustre lê a parte PDF do arquivo.
- **Atualização:** o programa se atualiza sozinho pela Suíte Angerô quando estiver fechado.

Outras dúvidas: fale com o TI do Grupo Angerô.
