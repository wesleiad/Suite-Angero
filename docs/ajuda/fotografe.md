# Fotografe - Angerô — Ajuda

Programa de **edição de imagens** da Suíte Angerô: fotos de produto, montagens, ajustes de cor, mockups.
Menus, ferramentas e atalhos no padrão do Photoshop.

## Abrir

- Menu Iniciar › **Suíte Angerô** › **Fotografe - Angerô**, ou pelo iniciador **Suíte Angerô**.
- Abre e salva **PSD/PSB** com camadas, além de PNG, JPG, TIFF, WebP, BMP, GIF e TGA.

## Onde fica cada coisa

| Quero… | Onde |
|---|---|
| Recortar | Ferramenta Corte (C) |
| Ajustar brilho/cor | Imagem › Ajustes (Níveis Ctrl+L, Curvas Ctrl+M, Matiz/Saturação Ctrl+U) |
| Ajuste sem estragar a foto | Camada › Nova camada de ajuste |
| Tirar fundo | Selecionar › Assunto, depois máscara de camada |
| Máscara | Botão de máscara no painel Camadas |
| Sombra, contorno, brilho | Camada › Estilo de camada |
| Texto | Ferramenta Texto (T) |
| Redimensionar | Imagem › Tamanho da imagem (Ctrl+Alt+I) |
| Salvar para web | Arquivo › Exportar › Salvar para Web |
| Processar várias fotos | Arquivo › Automatizar › Lote |

Atalhos: **V** mover, **M** letreiro, **L** laço, **W** seleção rápida, **B** pincel, **E** borracha, **J** correção,
**Ctrl+J** duplicar camada, **Ctrl+T** transformação livre, **Ctrl+Z** desfazer.
