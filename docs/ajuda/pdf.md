# PDF - Angerô — Ajuda

Programa de **PDF** da Suíte Angerô: ler, organizar páginas, juntar, dividir, assinar, proteger e imprimir.

## Abrir

- Menu Iniciar › **Suíte Angerô** › **PDF - Angerô**, ou dê dois cliques num PDF (se o PDF - Angerô for o padrão).

## Onde fica cada coisa

| Quero… | Como |
|---|---|
| Juntar PDFs | Tela inicial › **Combinar** (arraste os arquivos e ponha na ordem) |
| Tirar ou girar páginas | Organizar páginas (miniaturas): selecione e use girar/excluir |
| Extrair algumas páginas | Organizar páginas › selecione › Extrair |
| Procurar texto | Ctrl+F |
| Imprimir | Ctrl+P |
| Proteger com senha | Arquivo › Proteger |
| Várias abas | cada PDF abre numa aba; clique direito na aba para fechar/reabrir |

## Assistente de IA

Pelo iniciador **Suíte Angerô**: *"abre o PDF do pedido 123"*, *"como junto dois PDFs?"*.

Outras dúvidas: fale com o TI do Grupo Angerô.
