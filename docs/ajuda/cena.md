# Cena - Angerô — Ajuda

Programa de **edição de vídeo** da Suíte Angerô: vídeos de coleção, redes sociais, treinamentos.
Painéis, ferramentas e atalhos no padrão do Premiere.

## Abrir

- Menu Iniciar › **Suíte Angerô** › **Cena - Angerô**, ou pelo iniciador **Suíte Angerô**.
- Importa MP4/MOV, áudio (WAV, MP3, FLAC, AIFF, OGG) e imagens.

## Primeiros passos

1. **Importar:** arraste os arquivos para o painel Projeto (ou Arquivo › Importar, Ctrl+I).
2. **Montar:** arraste os clipes para a Linha do tempo.
3. **Cortar:** ferramenta Navalha (**C**) ou posicione e use Ctrl+K; **V** volta para a seleção.
4. **Texto/legenda:** ferramenta Texto no monitor do programa (**T**).
5. **Áudio:** Mixer de faixas de áudio; ganho em Clipe › Opções de áudio.
6. **Exportar:** Arquivo › Exportar › Mídia (Ctrl+M) — para redes sociais, H.264 (MP4).

Atalhos: **Espaço** reproduzir/pausar, **J/K/L** voltar/pausar/avançar, **I/O** marcar entrada/saída,
**+/−** zoom da linha do tempo, **Ctrl+Z** desfazer.

Outras dúvidas: fale com o TI do Grupo Angerô.
