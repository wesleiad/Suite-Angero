# LightBridge - Angerô — Ajuda

**Catálogo e revelação de fotos** da Suíte Angerô: organizar fotos de produto e de campanha, dar nota, etiquetar,
ajustar em lote e exportar.

## Abrir

- Menu Iniciar › **Suíte Angerô** › **LightBridge - Angerô**, ou pelo iniciador **Suíte Angerô**.
- Lê JPG, PNG, TIFF e arquivos RAW de câmera (CR2, CR3, NEF, ARW, DNG, RAF, ORF, RW2).

## Onde fica cada coisa

| Quero… | Como |
|---|---|
| Trazer fotos | Arquivo › Importar fotos… ou Importar de pasta… |
| Ver uma pasta sem importar | Biblioteca › Procurar pasta |
| Dar nota / marcar | teclas **1–5** (estrelas), **P** escolhida, **X** rejeitada |
| Etiquetas | painel Palavras-chave |
| Álbuns | Biblioteca › Novo álbum |
| Ajustar a foto | módulo Revelar: Exposição, Contraste, Balanço de branco, Cor… |
| Copiar ajustes para várias | selecione várias › Sincronizar configurações |
| Exportar em lote | selecione › Arquivo › Exportar… (escolha tamanho, formato e pasta) |
| Editar no Fotografe | Foto › Editar em outro programa › **Fotografe - Angerô** |

Outras dúvidas: fale com o TI do Grupo Angerô.
